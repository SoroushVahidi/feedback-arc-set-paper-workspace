# Feedback Arc Set — Research Workspace

> Raw research workspace / staging area (not a polished release). This
> repository holds exploratory code and generated experiment outputs from
> the author's feedback-arc-set (FAS) research line — genetic/heuristic FAS
> algorithms, large-scale (Wulver HPC) batch runs, and ranking outputs on
> connectome and other large graphs.

For polished, documented, actively maintained repositories from this
research line, see:

- [ranking-by-feedback-arc-set](https://github.com/SoroushVahidi/ranking-by-feedback-arc-set) — Journal of Supercomputing manuscript and code
- [minimum-weighted-fas-heuristics](https://github.com/SoroushVahidi/minimum-weighted-fas-heuristics) — IPSNS heuristic, manuscript and reproduction package

## What's in this repo

- `codes/` — genetic/heuristic FAS implementations, HPC batch drivers
  (`feedback_two_heu_wulver-*.py`), notebooks.
- `datasets/` — generated ranking CSVs, log files, and plots from those runs
  (large; not curated as a citable dataset release).
